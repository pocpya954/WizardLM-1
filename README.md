# WizardLM

WizardLM is a family of open models built upon instruction tuning and Evol-Instruct strategies. The repository contains code, data processing scripts, and model configurations used to train and evaluate the WizardLM models. Please consult the relevant scripts and model cards for details about training and evaluation.
